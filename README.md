# GeneratorCraft Wiki

Welcome to the official **GeneratorCraft Wiki** — a comprehensive, community-friendly knowledge base for everything related to the GeneratorCraft Minecraft mod.

This wiki includes detailed documentation on:

### 🌍 Biomes & World Features  
Explore the unique GeneratorCraft environments such as the *Biome of Wealth*, including its custom mobs, structures, and resources.

### ⚙️ Generators & Upgrades  
Learn how generators work, how to upgrade them, and how to build efficient setups.

### 💰 Currency & Economy System  
Understand the mod’s banking system, currency items, multipliers, pricing rules, and money-making methods.

### 🔮 Corruption, Events & Special Mechanics  
Dive into corruption mechanics, rare events, item hoarder challenges, gem boosts, and more.

### 🧰 Commands & Admin Tools  
A complete reference of all available commands — both for players and server administrators.

### 🧪 Items, Lootboxes & Rarities  
Discover the catalog of items: lootbox drops, weapons, tools, potions, gems, and ultra-rare artifacts.

## About This Wiki

This site is powered by **MkDocs** with the **Material for MkDocs** theme.  
It is automatically updated from the contents of this repository.

Each Markdown file in the `docs/` folder corresponds directly to a page on the live wiki.
