Daily Rewards
 Every 24 hours at 00:00 the daily reward is reset. GeneratorCraft Level 5 is required to access it. Can be accessed using /daily ( 
#daily
 ) The Daily Rewards consist of: Coins: 
`(Random[1-200])*(GC_LEVEL)`
 Gems: 
`(Random[1-100])*(GC_LEVEL)`
 One random GeneratorCraft item (any item) One Slots spin
