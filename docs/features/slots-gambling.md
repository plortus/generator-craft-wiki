The 
Slot Machine
 is a feature in GeneratorCraft that allows you to gamble using Slot Tokens. The three slots in the GUI will roll a random item, if all three slots match the same item, the item is dropped as a reward. The loot has a forgiving system. Every spin adds 1 to the forgive counter. When the forgive counter surpasses 75 the table used to define the 3 items becomes much more empty and fair. When the counter reaches 200 it resets. The unforgiving table can have any GeneratorCraft item. The forgiving tables make all 3 slots include only: 
- Lootbox related items
- Weapon related items
- Generator related items
- Generator Upgrades related items
- Currency related items
