Combat Log
 Combat Logging is a state which occurs for a few seconds after the player was hit or dealt damage to an entity. The timer can be decreased by upgrading the Combat Log Timer or removed completely by setting CombatLogging ( 
#combat-logging
 ) to false. During being Combat Logged, the player may not use most GUIs, GeneratorCraft commands, open Lootboxes and more
