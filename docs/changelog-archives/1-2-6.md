## Changes:

- Some numbers should now display commas (",") if too big
- Main Menu, Background Dirt, and Menu Panorama have been changed to fit GeneratorCraft's aesthetic
- Added some buttons to the main menu
- Added custom Splash Texts to the main menu
- Coins and Gems will now display less than 1 coin (e.g., 5 coins → 5.25 coins)
- Events Rework: All events now run under the same clock instead of separately

- Every 50 minutes, a random event will take place for 25 minutes

 

### New Event: EmptiX Trade-in Event

- Upon eating food or drinking potions, a waste item will be dropped
- Waste items may be exchanged with the generous EmptiX corporation for Deposit Tokens
- Deposit Tokens may be used in the EmptiX Store while the event is active  
(Note: the store currently isn't selling anything)Added Current Event display under the currency overlay
- Added three new stats: World Bank, Economy State, and Economy Boost/MultiplierWorld Bank: Value of coins the "world" has (new world starts at 1,000,000)You can request a loan using /loan [request/replay] [amount]Failure to repay will result in a blockage of incomeEconomy State reflects the health of the economyEconomy Boost/Multiplier affects prices and outputAbove 1x → gets added to pricesBelow 1x → gets added to output of purchasesFor more info, refer to the GeneratorCraft Wiki Discord
