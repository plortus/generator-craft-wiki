## Changes

- Removed the /myplaytime command.
- Added 5 new generators: Gunpowder, Shulker Shell, Bone, Blaze Rod, and Ender Pearl.
- Added a new event: The Item HoarderThe Item Hoarder event activates every 37 minutes for 7 minutes.It will announce the item that may be sold to The Hoarder for 1 coin each via the /hoarder command.Eligible items for the event include: Rotten Flesh, Cake, Leather, Poisonous Potato, Recovery Compass, Clock, Spyglass, Wooden Pickaxe, Copper Ingot, and Rabbit Hide.
