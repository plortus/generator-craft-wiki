# Changelog

 

## Changes

- If the Developer of GeneratorCraft (ignDante) is in the same server as the player, everyone on the server will receive the "Played with the Developer" advancement.
- Added a short tutorial popup when playing GeneratorCraft for the first time.
- Added text to the lore of the Ultra Anvil that suggests it being usable as a villager workstation.
- Nerfed the Axe of Midas' weight in the Weapon Lootbox from 79 to 45.
- Removed the /gclevel command and moved its function to the Dev GUI.

## Fixes
- Fixed the Axe of Judgement being unobtainable from the Weapon Lootbox because it was replaced by the Worn Out Axe.

## Known Issues
- Using bed explosions in the Nether/End doesn't give coins/gems when killing mobs. [Likely won't fix]
- Using Riptide tridents with lightning rods doesn't give coins/gems when killing mobs. [Likely won't fix]
- Gem Multiplier events break after a while. [Unable to reproduce]
- Advertisement GUI might break and not load correctly. [I have fixed this; it keeps unfixing itself!]
Note: Need to do more server-side testing but have no one willing to or the time to do so.
