## Changes:

- Added a new ore to the Biome of Wealth: Fortunite
- Fortunite can be used in the Smithing Table to combine Netherite Gear with Gem Gear to create Fortunite Gear (slightly better than Netherite)
- Added Fortunite tools as optional tools in the Ultimate Shiny Breaker recipe
- Added Fortunite Ingots to the Gem Core Shrine loot table

- Added Daily Rewards (Unlocked at GeneratorCraft Level 5)

- Every day at 00:00 (computer time) they reset and can be claimed again using /daily

- Daily rewards include:
One random item from GeneratorCraft (every item has an equal chance of appearing)A set amount of Coins and Gems (multiplied by your GeneratorCraft Level)
