# Performance Update – Improving gameplay on both Servers and Singleplayer!

- Some features will now output information to the Minecraft log file

- This will heavily improve debugging in cases of crashes or other issues
- New Gamerule: doMobSpawningGeneratorCraft

- Toggles whether the mod's mobs should spawn or not
- Wealthy Mobs now spawn differently:

- Instead of spawning like any other mob, they now have a 1/30 chance to spawn when their regular counterpart spawns
- Most features that ran every tick will now run every second instead

- This might break some existing timers — please contact me if you encounter any issues or bugs from this change
