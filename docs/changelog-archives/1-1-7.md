## Changes:

- Sugar has been added to the Hoarder's desired items
- The Bank can no longer be upgraded with Condensed Gems. It will now cost 1,000 Coins and Gems
- Upgrading the max currency is now cheaper (100% of max -> 30% of max)
- Upgrading the max currency will now reward a bigger increase (10 -> 1,000)
- Added currencyLimit gamerule for limiting maximum currency
- While watching an Ad, it should no longer be possible to take damage
- Added a new structure: the Gem Core Shrine:

- Fairly rare, but comes with a lot of loot and the Gem Core block

- The Gem Core can be used to craft the Ultimate Shiny Breaker, a multitool (Pickaxe, Axe, Shovel, etc.)
- A few updates ago, the backend system for storing currencies was changed, along with the max currency feature being added. Some players lost all of their currencies when updating GeneratorCraft due to this:

- The command /pleaseforgiveus has been added for everyone to enjoy (this will be removed or changed next update)

- Grants 200 Coins, 100 Gems, and adds 1,000 to both Coin and Gem limits

 

## Fixes:

- Fully grown crops dropping coins should no longer trigger when breaking Fire
- Default values should no longer be reset to zero when updating GeneratorCraft
