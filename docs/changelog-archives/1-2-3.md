## Changes:

- Adblock price nerfed (75,000 Coins → 7,500 Coins, 10,000 Gems → 1,000 Gems)
- Watching an Advertisement now grants you a small amount of Coins and Gems
- The GeneratorCraft Store is now in dark mode, feedback appreciated!
- Box Chance will now display in the Currency Window if it's active or not
- Added a new admin-only command: /addcurrency [player] [coin/gems] [amount]
- Added a new upgrade: Price Multiplier!

- Upgrading it changes the price of pretty much everything!
- Added a new admin-only command: /setpricemultiplier [player] [amount]
