## Changes:

- You may now Shift-Click Condensed Gem Blocks to convert them into Digital Gems
- Generators now have a value from 0 to 2 called "workforce"

- Workforce 0: Default — generator works as usual

- Workforce 1: Requires redstone to operate

- Workforce 2: Generator is disabled

- Workforce can be cycled in the generator's menu

 

## Fixes:

- Fixed visual bug with the Rebirth Boost formatting when killing mobs
- Fixed description of Condensed Gem Block
- Fixed message formatting in the output of the /bank command
