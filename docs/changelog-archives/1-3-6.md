## Changes:

- EmptiX Pickaxe should now work with ores from other mods (as long as they are tagged in minecraft:ores)
- Removed unused code for a Split or Steal event and an Admin Panel GUI
- Dropping a Lootbox from killing a mob will now have a chance to drop another one if your weapon has the Looting enchantment

 
(Condition: if Random[LootingLevel-10] >= 5)
- Lowered the Watermark price from 70,000 Coins & 3,000 Gems → 6,500 Coins & 2,500 Gems

 

### New Feature: Generator ★ Star Levels!

- Every Generator is now a ★1 Star Level Generator
- Use the ★ Star Fusion Table ★ to fuse same-tier generators for a chance to upgrade to a higher ★ level!
- Highest level is ★5, each level significantly speeds up the generator
- Note: Fuse attempts require rebirths:
★1 → ★2: 70% success (Requires 1 Rebirth)★2 → ★3: 50% success (Requires 3 Rebirths)★3 → ★4: 25% success (Requires 7 Rebirths)★4 → ★5: 1% success (Requires 10 Rebirths)
## Fixes:
- Fixed a crash that could occur when breaking blocks with the EmptiX Pickaxe
