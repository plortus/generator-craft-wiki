RNG Miner
 RNG Miner is a Pickaxe enchantment that can go up to tier 3 (iii). It may be obtained though various loottables, villager trades and the enchantment table If the block broken is an ore, a random chance of 
`1/(Random[1-(50,000-EnchLevel*10000])`
 is rolled. If the roll is successful, a random amount (0 to 64) of goodies will drop. The Enchantment conflicts with Silk Touch and Fortune Money Pouch Gem Fortunite Ingot Diamond Iron Ingot Gold Ingot Slots Token Bank Token
