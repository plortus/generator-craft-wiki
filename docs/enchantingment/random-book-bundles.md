Random Book Bundle
 Random Book Bundle is an item that upon consuming, will grant a random enchantment book. It can be obtained from an Elite Enchantsmith ( 
#elite-enchantsmith-villager
 ) It comes in several types: 
- Random Book Bundle
- Random Book Bundle (Armor)
- Random Book Bundle (Weapon)
- Random Book Bundle (Mining)
- Random Book Bundle (Elite)

The Elite bundle is same as random, expect you may get enchantments much above their max level
