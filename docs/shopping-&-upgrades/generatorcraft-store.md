GeneratorCraft Store
 The GeneratorCraft Store can be accessed using /shop ( 
#shop
 ) or by pressing the default keybind of B (can be changed in minecraft control settings) In the store GUI there are several buttons and upgrades: 
- Coin drop chance upgrade
- Box drop chance upgrade [TOGGLE] (toggles whether you want to drop boxes or not)
- Coin multiplier upgrade
- Gem drop chance upgrade
- Combat Log time upgrade
- Price Multiplier upgrade
Adblock (remove advertisements #advertisements )
- Remove Watermark ( #watermark )
- Gem Shop ( #gem-shop )
- Slot Machine ( #slots-gambling )
- Banking ( #banking )
