Gemstone Obelisk
 The Gemstone Obelisk is a flex trophy block that can be bought from the Gem Shop ( 
#gem-shop
 ) As of GeneratorCraft 1.2.4, the Obelisk's price does not get reduced by the Price Multiplier After placing it down, right-clicking it will set an owner to it. Right-Clicking an obelisk that already has an owner will show in chat who own's it. Breaking an obelisk that doesn't belong to you will return it to it's owner. While holding an obelisk, could be converted back to Gems using 
`/convertobelisk`
 ( 
#convertobelisk
 )
